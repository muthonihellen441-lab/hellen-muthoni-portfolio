## Project Overview

This is a personal portfolio website for **Hellen Muthoni Wanjiru** — a Fashion Designer and Creative Director based in Nairobi, Kenya. The site was built as part of the Moringa School AI Capstone project, using **TailwindCSS** as the chosen technology and **Claude AI** as the primary learning and development tool.

The goal was to:
- Learn TailwindCSS from scratch using AI prompts
- Build a real, deployable portfolio website
- Document the process clearly so others can replicate it

##  How to Run Locally

No installations required. Just:

1. **Clone or download this repository**
```bash
git clone https://github.com/yourusername/hellen-muthoni-portfolio.git
```

2. **Open the project folder**
```bash
cd hellen-muthoni-portfolio
```

3. **Open `index.html` in your browser**
   - Double-click the file, OR
   - Right-click → Open with → Chrome / Firefox / Edge

That's it! The site uses the Tailwind CDN so no build step or npm is needed.

>  Make sure `Msoo.jpg` and `index.html` are in the **same folder** for the profile photo to display correctly.

##  AI Prompt Usage

This project was built entirely with the assistance of **Claude AI (claude.ai)**. Key prompts included:

- Asking Claude to explain TailwindCSS for a complete beginner
- Requesting a full portfolio page with a specific aesthetic brief (editorial, high-fashion, dark + gold palette)
- Uploading a CV and portfolio PDF and asking Claude to fill in all real content
- Asking Claude to explain each Tailwind class used, to aid learning

Full prompt documentation with responses and reflections is available in [`toolkit.md`](./toolkit.md).

##  Common Issues

| Issue | Fix |
|---|---|
| Photo not showing | Ensure `Msoo.jpg` is in the same folder as `index.html` |
| Tailwind not working | Check that the CDN `<script>` tag is inside `<head>` |
| Fonts not loading | Requires internet connection; Google Fonts link must be in `<head>` |
| GitHub Pages blank page | File must be named exactly `index.html` |
| Mobile layout broken | Use responsive Tailwind prefixes like `md:grid-cols-2` |
